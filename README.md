# Restaurant Management System

A full-stack Restaurant Management System built with Spring Boot and React.

## Features

- QR Code table ordering
- Customer self-service ordering
- Kitchen workflow
- Waiter workflow
- Order tracking
- Real-time status updates
- Payment workflow
- Inventory management
- Staff management
- JWT Authentication
- Role-based access (Admin, Chef, Waiter)

## Tech Stack

Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- JWT

Frontend
- React
- Vite
- React Router

## Roles

- Admin
- Chef
- Waiter
- Customer (QR Ordering)
